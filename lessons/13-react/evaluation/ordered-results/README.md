## 비교 조건

- 이전 [8회 결과](../results/README.md)와 같은 한국어 지시 4개, 시드 9201의 배치 A와 시드 9302의 좌우 반전 배치 B를 사용했습니다. 각 쌍에서 최초 관절·차체 자세, 두 블록과 목표 좌표가 일치하는지 확인했습니다.
- Isaac Sim 6.1, Qwen2.5 7B, 배포된 Waffle 색상 정책과 부모 VLA 체크포인트, 6턴 예산, [물리 채점 코드](../score.py)를 유지했습니다. 목표 위치, 들기 높이, 다른 블록 운반 여부, 촬영 순서와 횟수, 종료 상태를 함께 채점합니다.
- Qwen이 촬영·운반 순서를 먼저 작성하면 실행기가 각 행동 결과를 확인하며 다음 단계로 넘어갑니다. 좌우 지시는 최초 로봇 자세에서 구한 횡방향 좌표로 해석합니다. 조건이 있는 작업이나 실행 오류가 발생한 경우에는 현재 상태와 행동 기록을 사용해 다음 행동을 다시 결정합니다.
- 각 시험 폴더의 `task.json`은 Qwen이 생성한 최초 계획입니다. 순서 실행에서 `finish`는 계획에 있는 행동이 오류 없이 끝났을 때 실행기가 생성합니다. 이전 방식에서는 Qwen이 매 턴 종료 여부를 선택했습니다.
- 이미 실패 사례를 분석한 조건의 재시험이므로 새로운 지시나 배치에 대한 일반화 성능은 별도 실험이 필요합니다. 이번 변경과 측정의 대상은 Isaac 실행기입니다.
